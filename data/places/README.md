# data/places

Generated by `pnpm run places:build` from GeoNames (geonames.org, CC BY 4.0). Do not edit by hand.

| File | Contents |
| --- | --- |
| `cities.csv.gz` | GeoNames `cities1000` US rows for the ten seed states (NY, NJ, CT, PA, CA, FL, AZ, MO, IL, GA): `id,slug,name,state,lat,lng,population,time_zone`. One row per state and slug; when two places share a name in a state, the most populous is kept. |
| `zips.csv.gz` | GeoNames US postal codes for the same states: `zip,lat,lng,city_id,place,state`. `city_id` is the same-name city in the state, else the nearest city within 30 km, else empty. `place` and `state` are not `zips` columns; they locate places under 1,000 people (Gladwyne, PA) for the 25 km matching rule. |
| `metros.yaml` | The 500 most populous US cities (all states, neighbourhoods excluded), for search-by-place queries. |

`pnpm run places:build --all` writes every state instead of the ten (large; don't commit it without the owner's say-so). `pnpm run places:load` fills the local D1 `cities` and `zips` tables; `pnpm run seed` does it as part of the full reload. Downloads are cached in `.cache/geonames/`.

The /about page credits GeoNames with `GEONAMES_ATTRIBUTION_TEXT` from `@gof/shared/places`.
